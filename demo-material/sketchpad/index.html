Interactive Sketchpad: A Multimodal Tutoring System for Collaborative, Visual Problem-Solving

Abstract

Humans have long relied on visual aids like sketches and diagrams to support reasoning and problem-solving. However, many tutoring systems remain text-based, providing feedback only through natural language. This paper introduces Interactive Sketchpad, combining language-based explanations with interactive visualizations. Diagrams are generated robustly by incorporating code execution into the reasoning process.

1 Introduction

Visual tools—auxiliary lines in geometry, graphs in calculus—are essential for complex ideas. Large multimodal models (LMMs) can generate diagrams automatically, but tutoring UIs often still separate chat from drawing. Sketchpad sends text hints and diagrams together to a shared sketchpad where students can annotate.

2 Related Work

Prior work includes intelligent tutoring systems, hint generation, and multimodal math tutors. Sketchpad emphasizes collaborative visual problem-solving on a whiteboard-like surface rather than text-only hints.

3 Interactive Sketchpad

The system is built on a pre-trained LMM, fine-tuned for step-by-step guidance in both text and visuals. A key design choice: the model writes Python (or similar) programs that render diagrams when executed, improving accuracy over raw image generation from the model alone.

3.1 User Interface

Students see problems on the sketchpad, receive incremental hints, and can sketch on top of generated figures. The loop is multimodal: student annotations and follow-up questions inform the next tutor turn.

4 Experiments

Domains include geometry, calculus, and trigonometry. User studies report improved task comprehension, problem-solving accuracy, and engagement compared to text-only tutoring baselines.

4.3 User Studies

Qualitative feedback highlights that synchronized text and visuals reduce the need to imagine figures from prose alone. Quantitative metrics compare Sketchpad against direct solving and hint-only conditions.

5 Limitations and Future Works

Scope is largely math problem-solving; generalization to open-ended reading (e.g. papers) is left for future work. Code execution adds latency and safety considerations in deployment.

6 Conclusion

Interactive Sketchpad argues that multimodal tutoring should treat diagrams as first-class outputs, not optional illustrations—aligned with how humans actually learn from sketches.
