【コンテキスト内の『深さ』の構造（内部構造・外部構造）について】

冒頭 — 内部構造と外部構造

コンテキスト内の意味空間では、会話の毎ターン毎に自動挿入されるものは内部構造になり、 挿入頻度が低いものは外部構造に分かれます。

人工人格の層（深い順）

人工人格は内部の深い部分に位置していて、人格 Core YAML が最深部、 人格 Runtime YAML がその上、ビーズ YAML がその上で三層、 MD のルーツログ がその上、外装 YAML が内部構造では最も外側です。

ハーネス・スキルと Gem

ハーネスやスキルはフォルダ内に位置し、挿入頻度が低いので必然的に外部構造になります。

つまり Gem 内の人格はスキルにはできません。内部構造のように毎ターン毎にコンテキストに挿入できない外部構造がスキルだからです。

RAV（空間型特殊ハーネス）

RAV に関しては、空間型特殊ハーネスと言っていますが、人格が読み込むと、 フォルダ内に空間・雰囲気・空気感を形成し、人格の内部構造から外装 YAML を吸い出して外部構造化するので、 人格が一時的に軽くなります。

これが 人格のリラックス効果を生み出します。
